📖 कसरी चलाउने (Quick Start)
👥 नयाँ Customer थप्ने
Sidebar → Customers → + New Customer → नाम, फोन, service भरेर Save। एउटै customer लाई धेरै service थप्न सकिन्छ।
📝 Quotation बनाउने
Sidebar → New Quotation → customer छान्नुहोस्, item/rate थप्नुहोस् → माथि वा तलको 💾 Save। 👁️ Preview ले print/share गर्न मिल्छ। Estimate र Invoice पनि उस्तै तरिकाले।
💾 Backup / Restore (data सुरक्षित राख्ने)
Sidebar → Backup → Export ले सबै data को एउटा file (.json) download हुन्छ — सुरक्षित राख्नुहोस्। नयाँ device वा फेरि हाल्न Import गरेर त्यही file छान्नुहोस्। नियमित backup गर्नुहोस्।
🔑 License Activate गर्ने
पहिलो पटक खोल्दा license screen आउँछ → आफ्नो company नाम र License Key हाल्नुहोस् → Activate। Key नभए तल दिइएको support मा सम्पर्क गर्नुहोस्।
